# 31 Capitals — landing page preview

A static copy of the 31 Capitals landing page, published so it can be reviewed without a server.

**The enquiry form is inactive here.** GitHub Pages serves static files only. On the live site the form emails a six-digit verification code, checks it on the same page, and then opens the partner brokerage's registration page with the introducing-broker identifier attached.

The market desk shows clearly-labelled sample data. It switches to live content once the partner brokerage's API endpoints are configured.
